# Endpoints utilisés

## Shopify

- GraphQL Admin : `https://{shop}.myshopify.com/admin/api/{version}/graphql.json`
- OAuth authorize : `https://{shop}.myshopify.com/admin/oauth/authorize`
- OAuth token : `https://{shop}.myshopify.com/admin/oauth/access_token`

## AliExpress

- Passerelle internationale : `https://api-sg.aliexpress.com/rest`
- OAuth : `https://api-sg.aliexpress.com/oauth/authorize`
- Passerelle Dropshipping TOP : `https://eco.taobao.com/router/rest`
- Méthodes : `aliexpress.ds.product.get`, `aliexpress.ds.recommend.feed.get`, `aliexpress.logistics.buyer.freight.calculate`, `aliexpress.trade.buy.placeorder`, `aliexpress.trade.ds.order.get`, `aliexpress.logistics.ds.trackinginfo.query`.
